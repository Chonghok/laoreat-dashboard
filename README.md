# Laoreat Admin Dashboard
A web-based administrative dashboard developed as part of the Laoreat university group project, which also includes a mobile application

## Technologies
- HTML
- CSS
- JavaScript

## Features
- Administrative interface for the Laoreat project
- Interface integration with the backend API
- Products, categories, price, discount management
- Promotional codes management
- Order history record
- Reviews monitoring

- **Backend API:** [laoreat-api](https://github.com/Chonghok/laoreat-api)
- **Admin Dashboard:** This repository
- **Mobile Application:** Developed collaboratively with the project team
